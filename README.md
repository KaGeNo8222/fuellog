# FuelLog — บันทึกเติมน้ำมัน

เว็บแอป (PWA) สำหรับ iPhone: บันทึกการเติมน้ำมัน คำนวณ กม./ลิตร และสรุปค่าน้ำมันรายเดือน ใช้งานออฟไลน์ได้ ข้อมูลเก็บในเครื่องเท่านั้น

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแอป |
| `style.css` | หน้าตา (รองรับโหมดมืดอัตโนมัติ) |
| `logic.js` | การคำนวณ อ่านข้อความจากโน้ต และ CSV |
| `app.js` | หน้าจอ ฟอร์ม กราฟ การเก็บข้อมูล |
| `sw.js` | ทำให้เปิดแอปได้แม้ไม่มีเน็ต |
| `manifest.webmanifest`, `*.png` | ชื่อและไอคอนแอปบนหน้าจอโฮม |
| `fonts/` | ฟอนต์ Sarabun (รุ่นเว็บของ TH Sarabun New, สัญญาอนุญาต OFL ใน `fonts/OFL.txt`) |

## ติดตั้งครั้งแรก (ไม่ต้องใช้ git)

1. สมัคร GitHub ฟรีที่ https://github.com/signup
2. กดปุ่ม **+** มุมขวาบน → **New repository** → ตั้งชื่อ เช่น `fuellog` → เลือก **Public** → **Create repository**
3. ในหน้า repository ที่ว่างอยู่ คลิกลิงก์ **uploading an existing file** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ **รวมทั้งโฟลเดอร์ `fonts`** ไปวาง → กด **Commit changes**
4. ไปที่ **Settings** → **Pages** → ช่อง Branch เลือก `main` และ `/ (root)` → **Save**
   รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/fuellog/`
5. บน iPhone เปิดลิงก์นั้นด้วย **Safari** → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** (ถ้ามีตัวเลือก "เปิดเป็นแอปบนเว็บ" ให้เปิดไว้)
6. เปิดแอปจากไอคอน FuelLog → แท็บ **ตั้งค่า** → วางข้อความที่จดไว้ในโน้ต → **อ่านข้อความและนำเข้า**

> repository แบบ Public จะมีคนอื่นเห็นได้แค่โค้ด ส่วนข้อมูลการเติมน้ำมันอยู่ใน iPhone เท่านั้น ไม่ได้ขึ้นไปบน GitHub

## สำรองข้อมูล

ข้อมูลเก็บอยู่ในแอปบน iPhone ถ้าลบไอคอนแอปออก ข้อมูลจะหายไปด้วย
ควรเข้า **ตั้งค่า → ส่งออกเป็นไฟล์ CSV → บันทึกไปยังแอปไฟล์ (iCloud Drive)** เป็นระยะ
(แอปจะขึ้นแถบเตือนเมื่อไม่ได้สำรองเกิน 30 วัน) ไฟล์ CSV เปิดใน Excel ได้ และนำเข้ากลับได้ทางปุ่ม **นำเข้าจากไฟล์ CSV**

## อัปเดตแอปหลังแก้ไฟล์

1. เปลี่ยนเลข `VERSION` ใน `sw.js` (เช่น `1.0.0` → `1.0.1`) และ `APP_VERSION` ใน `app.js` ให้ตรงกัน
2. ใน GitHub กด **Add file → Upload files** แล้วลากไฟล์ที่แก้ไปวางทับ → **Commit changes**
3. เปิดแอปบน iPhone จะมีแถบ "มีเวอร์ชันใหม่ แตะเพื่อโหลด" ขึ้นมา

## ลองบนคอมพิวเตอร์

ดับเบิลคลิก `index.html` เพื่อเปิดใน Edge หรือ Chrome ได้เลย ข้อมูลที่กรอกบนคอมพิวเตอร์จะอยู่ใน browser ของเครื่องนั้น ไม่ได้เชื่อมกับ iPhone
